## 2. 为实时变化额外增加的数据（重要）

论文表本身没有「按秒刷新」的序列，若要图表实时动起来，前端需要补充一套**演示用动态参数**。

### 新增文件

| 文件 | 作用 |
|------|------|
| `live_params.json` | 实时扰动参数：更新间隔、各算法振幅/频率/相位/噪声 |

路径：`public/cl_data/chapter2/live_params.json`

### 参数含义

| 字段 | 含义 | 当前取值 |
|------|------|----------|
| `updateIntervalMs` | 图表刷新间隔 | `1000`（每秒一次） |
| `clamp` | 纵轴裁剪范围 | `[0, 1]` |
| `algorithms.*.amp` | 相对基线的正弦振幅 | 见下表 |
| `algorithms.*.omega` | 角频率（相对时间 t，单位约 rad/s） | 见下表 |
| `algorithms.*.phase` | 初相位 | 见下表 |
| `algorithms.*.noise` | 二次高频扰动幅度 | 见下表 |
| `pointPhaseStep` | 同一曲线上相邻横轴点的相位差 | `0.35` |

### 各算法实时参数（本次新增）

| 算法 | amp | omega | phase | noise |
|------|-----|-------|-------|-------|
| Dijkstra | 0.035 | 0.55 | 0.0 | 0.008 |
| DQN | 0.028 | 0.62 | 0.7 | 0.007 |
| PPO | 0.025 | 0.48 | 1.4 | 0.006 |
| PPO+DP | 0.018 | 0.40 | 2.1 | 0.004 |
| SEA | 0.040 | 0.70 | 2.8 | 0.010 |

> `PPO+DP` 振幅最小，曲线最稳，便于和论文结论「更优且更稳」的观感一致。

### 实时计算公式（新增逻辑）

对每个算法、每个横轴点 \(i\)，在时刻 \(t\)（秒）：

\[
live[i] = \mathrm{clamp}\Big(
  base[i]\cdot\big(1 + amp\cdot\sin(\omega t + \phi + i\cdot \Delta)\big)
  + noise\cdot\sin(2.3\,\omega t + i)
,\ 0,\ 1\Big)
\]

其中：
- \(base[i]\)：论文表导出的基线值  
- \(\Delta\) = `pointPhaseStep`  
- \(\mathrm{clamp}\) 到 \([0,1]\)

**说明：这是演示动效，不是新的仿真实验结果。** 曲线会在论文基线附近小幅波动，方便展示「实时监测」效果。

## 3. 前端如何使用

1. 加载对应 `*.json` 作为 `base`  
2. 加载 `live_params.json`  
3. 每 `updateIntervalMs` 用上式重算 `live` 并 `setOption` 更新 ECharts  
4. 可暂停/继续实时刷新  

开关在「实验结果」面板标题旁：**实时** 按钮。
